随身同传

连好蓝牙耳机，按下方按钮说话
  1. 在手机的蓝牙设置里连接耳机（任何品牌都行）
  2. 面对面：轮到谁说就按谁的按钮，说完再按一次
  3. 同传收听：持续听对方说话，译文在耳机里逐句播报

设置

翻译引擎

在 platform.openai.com › API keys 新建密钥。API 按用量单独计费，不包含在 ChatGPT 会员里；中国大陆和香港无法使用。

需要该服务允许浏览器直接调用。翻译失败时会自动改用免费引擎。

播报

iPhone 连着蓝牙耳机时，网页的声音一定从耳机出来；要外放请先断开耳机，或用 iOS 原生版。外放时，同传会在播报期间暂停收音，避免把自己的声音录进去。也可以点顶部的喇叭按钮快速切换。

使用提示

  1. iPhone：用 Safari 打开；需要在 设置 › 通用 › 键盘 中打开「启用听写」。
  2. 安卓：用 Chrome 打开。Chrome 的语音识别依赖 Google 服务，在中国大陆可能无法使用。
  3. 点浏览器的「分享 › 添加到主屏幕」，以后就能像 App 一样从桌面打开。
  4. 网页在锁屏后会暂停，所以收听时会尽量保持屏幕常亮。
  5. 网页无法单独把声音切到手机外放：面对面时可以用「大字」给对方看，或者分一只耳机给对方戴。
