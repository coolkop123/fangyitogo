# 酷天同声 · 手机网页版

用手机浏览器打开就能用，不用安装；也可以「添加到主屏幕」，像 App 一样从桌面打开。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 整个应用（界面 + 逻辑都在这一个文件里） |
| `manifest.webmanifest`、`sw.js`、`*.png` | 用于添加到主屏幕的图标和离线缓存 |

## 部署（必须是 https 网址，浏览器才允许用麦克风）

把整个文件夹放到任意静态网站托管上即可，以下任选一种：

- **Netlify Drop（最快，约 1 分钟）**：电脑打开 https://app.netlify.com/drop ，把文件夹拖进去，马上得到一个 `https://xxx.netlify.app` 网址。注册免费账号后网址会长期保留。
- **Cloudflare Pages / Vercel / GitHub Pages**：同样免费，上传文件夹就行。
- **国内访问更快**：阿里云 OSS、腾讯云 COS 等对象存储都支持「静态网站托管」。绑定自己的域名需要先做 ICP 备案。

部署好后，在手机上打开这个网址。

## 手机上怎么用

1. 先在手机的蓝牙设置里连上耳机，任何品牌都可以。网页会自动用系统当前的麦克风和扬声器。
2. **iPhone**：用 **Safari** 打开。先到 设置 › 通用 › 键盘，打开「**启用听写**」，网页语音识别要用到它。
3. **安卓**：用 **Chrome** 打开。Chrome 的语音识别依赖 Google 服务，在中国大陆可能用不了。
4. 第一次点话筒时，允许网站使用麦克风。
5. 加到桌面：Safari 点「分享 › 添加到主屏幕」，Chrome 点菜单「添加到主屏幕 / 安装应用」。

## 手机外放

点顶部的 🔊 喇叭按钮（或在设置里选「声音从哪里播放 › 手机外放」），译文会从手机扬声器大声播出，而不是从听筒小声出来。
- 同传模式下打开外放，播报期间会自动暂停收音，播完再继续，避免把自己播出的声音又识别一遍。
- iPhone 连着蓝牙耳机时，网页的声音一定从耳机出来。想外放就先断开耳机，或者用 iOS 原生版：原生版可以一边戴着耳机，一边让手机外放。

## 翻译引擎（在右上角 ⚙ 设置里切换）

| 引擎 | 费用 | 中国大陆 | 说明 |
|---|---|---|---|
| Google 翻译 | 免费 | 通常连不上 | 默认引擎。失败时自动改用 MyMemory |
| **ChatGPT** | 按用量付费（API 单独计费，不含在 ChatGPT 会员里） | 不可用 | 翻译最自然，能纠正语音识别听错的字。只需粘贴 OpenAI API Key（在 platform.openai.com › API keys 新建），模型默认 `gpt-4o-mini`，可以改。设置里有「测试连接」按钮 |
| MyMemory | 免费（每天 5000 字，填邮箱后 50000 字） | 可用 | 质量一般 |
| 大模型 API | 按用量付费 | 取决于服务商 |填写 OpenAI 兼容的接口地址、API Key 和模型名（例如 DeepSeek：`https://api.deepseek.com/v1` + `deepseek-chat`）。前提是该服务允许浏览器直接调用（CORS） |

API Key 只保存在你这台手机的浏览器里。但如果把网址分享给别人，他们需要自己填 Key。

## 和 iOS 原生版相比

| | 网页版 | iOS 原生版 |
|---|---|---|
| 安装 | 打开网址即可 | 需要 Mac + Xcode |
| 锁屏后继续收听 | ✗（收听时会保持屏幕常亮） | ✓ |
| 离线翻译 | ✗ 需要联网 | ✓ 苹果离线翻译 |
| 不戴耳机时外放 | ✓ 顶部喇叭按钮 | ✓ |
| 戴着耳机时：我说的话外放、对方的话进耳机 | ✗ 可用「大字」给对方看 | ✓ |
| 安卓 | ✓ | ✗ |
